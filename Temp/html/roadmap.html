30-Day UI/UX Design Learning Roadmap

Initial Setup and Tools

🕐 60 minutes ⭐ Difficulty: 1/5

Required Tools (All Free)

  • Figma (Web-based)
  • Penpot (Open-source alternative to Figma)
  • Google Chrome or Firefox
  • Notion (Free plan)
📚 Setup Resources:
  • Figma: figma.com
  • Penpot: penpot.app
  • Notion: notion.so
✅ Completion Criteria:
  • All tools installed and accounts created
  • Test projects created in both Figma and Penpot
  • Notion workspace set up with provided templates

Week 1: Foundations

Day 1: Design Fundamentals

Block 1

🕐 90 minutes ⭐ Difficulty: 2/5

1. Design Thinking Introduction

  • Watch "Design Thinking in 3 Minutes" by IDEO
  • Read "The Design Thinking Process" guide
  • Take notes on key concepts
📚 Learning Resources:
  • Primary: DesignKit.org - Introduction to Design Thinking
  • Backup: Stanford d.school's Design Thinking Crash Course
✅ Completion Criteria:

Create a mind map of design thinking principles and their applications

2. UI Elements Fundamentals

🕐 90 minutes ⭐ Difficulty: 2/5
  • Study basic UI elements (buttons, forms, cards)
  • Analyze examples from Material Design
  • Create basic element library in Figma
📚 Learning Resources:
  • Primary: Material Design Guidelines
  • Backup: Apple Human Interface Guidelines
✅ Completion Criteria:

Create a basic UI kit with 5 essential elements (buttons, input fields, cards, navigation, icons)

Block 2

🕐 120 minutes ⭐ Difficulty: 3/5

1. Color Theory Foundations

  • Study color psychology and meaning
  • Learn color harmony rules
  • Practice with color wheel tools
  • Create sample palettes
📚 Learning Resources:
  • Primary: Coolors.co color theory guide
  • Backup: Adobe Color Wheel (free)
✅ Completion Criteria:
  • Create 3 different color palettes using different harmony rules
  • Document the psychology behind each palette

2. Typography Basics

  • Learn type anatomy
  • Study font pairing principles
  • Practice with Google Fonts
📚 Learning Resources:
  • Primary: Typewolf's Typography Resources
  • Backup: Google Fonts Knowledge
✅ Completion Criteria:
  • Create 3 font pairing combinations with rationale
  • Build a simple type scale system

Block 3

🕐 120 minutes ⭐ Difficulty: 3/5

1. Mini-Project: Landing Page Header

  • Apply learned color theory
  • Implement typography principles
  • Create responsive grid layout
  • Design navigation elements
✅ Completion Criteria:
  • Complete header design with:
    • Logo placement
    • Navigation menu
    • Call-to-action button
    • Proper color scheme
    • Typography hierarchy
  • Document design decisions and rationale

2. Daily Review and Community Engagement

🕐 30 minutes ⭐ Difficulty: 1/5
  • Join Figma Community
  • Share header design in UI/UX beginners community
  • Review and document key learnings
  • Plan modifications based on initial learning experience
✅ Completion Criteria:
  • Daily learning log completed
  • Community profile set up
  • First design shared for feedback
  • Action items noted for Day 2

Day 2: Layout and Visual Hierarchy

Block 1

🕐 90 minutes ⭐ Difficulty: 3/5

1. Grid Systems and Layout

  • Study grid theory fundamentals
  • Learn different grid types (column, modular, baseline)
  • Practice with Figma's grid tools
📚 Learning Resources:
  • Primary: Grid Systems in Graphic Design by Josef Müller-Brockmann (Summary)
  • Backup: Figma's Grid Tutorial
✅ Completion Criteria:
  • Create three different grid systems (8, 12, and 16 columns)
  • Document use cases for each grid type

2. Visual Hierarchy Principles

🕐 90 minutes ⭐ Difficulty: 3/5
  • Study Gestalt principles
  • Learn scanning patterns (F-pattern, Z-pattern)
  • Analyze successful website layouts
📚 Learning Resources:
  • Primary: Interaction Design Foundation - Visual Hierarchy
  • Backup: UX Planet's Visual Hierarchy Guide
✅ Completion Criteria:

Create analysis document of 3 popular websites identifying their visual hierarchy patterns

Block 2

🕐 120 minutes ⭐ Difficulty: 4/5

1. Responsive Design Principles

  • Learn mobile-first design approach
  • Study breakpoints and fluid layouts
  • Practice with auto-layout in Figma
📚 Learning Resources:
  • Primary: Figma's Auto-layout Documentation
  • Backup: Material Design's Responsive Layout Grid
✅ Completion Criteria:
  • Create responsive layout for one component (e.g., navigation menu)
  • Document responsive breakpoints and behavior

2. Whitespace and Spacing Systems

  • Learn about spatial rhythm
  • Study 8-point grid system
  • Practice with spacing scales
✅ Completion Criteria:
  • Create spacing system documentation
  • Apply spacing system to yesterday's header design

Block 3

🕐 120 minutes ⭐ Difficulty: 4/5

1. Mini-Project: Feature Section

  • Design responsive feature grid
  • Apply visual hierarchy principles
  • Implement proper spacing system
  • Create mobile and desktop versions
✅ Completion Criteria:
  • Complete feature section design with:
    • Responsive grid layout
    • Clear visual hierarchy
    • Consistent spacing
    • Mobile and desktop variations

2. Portfolio Progress and Community Engagement

🕐 30 minutes ⭐ Difficulty: 2/5
  • Document design process
  • Share work-in-progress in community
  • Collect and organize feedback
✅ Completion Criteria:
  • Process documentation completed
  • Feedback collected and organized
  • Action items noted for Day 3

📚 Learning Resources:
  • Primary: Figma's Interactive Components Tutorial
  • Backup: Micro-interactions in UI Design Guide
✅ Completion Criteria:

Create 3 micro-interactions for common UI elements

Block 2

  • Primary: Figma Variants Tutorial

✅ Completion Criteria:
  • Create a complete component with all states for:

  • Study focus states
  • Understand error states and feedback
✅ Completion Criteria:
  • Audit and update all components for accessibility
